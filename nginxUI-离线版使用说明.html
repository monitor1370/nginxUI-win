适用版本：v1.1.0　适用系统：Windows Server 2016 及以上 / Windows 10、Windows 11（64 位）　权限要求：管理员

本文档面向不熟悉 nginx 的运维与开发人员，说明在无外网或不便联网的 Windows 服务器上，如何用 nginxUI 完成「安装实例 → 启停 → 改配置 → 升级 → 替换证书 → 启用 HTTPS」的完整流程。

本文档为纯 HTML，不含脚本与外部样式，可直接在百度 UEditor 中全选粘贴使用。

一、产品概述

nginxUI 是一个 nginx 图形化管理工具，把 nginx 以 Windows 服务的方式纳管，提供安装、升级、配置编辑、证书替换、站点 HTTPS 启用、启停与状态监控等能力，所有会改动配置的操作都会先执行 nginx -t 校验，失败不落地。

核心约定：

  • 每个实例对应一个 Windows 服务，服务名格式为 nginx-win-ngui-N。
  • 同一时刻只允许执行一个长操作（安装、升级、回滚、证书写入、监控写入、启停），其它入口会自动置灰并提示原因。
  • 所有危险操作都会弹出确认框，文案包含「操作对象 + 后果 + 是否可撤销」，默认按钮为「取消」。

二、运行环境与前置条件

项目 要求
操作系统 Windows Server 2016 及以上；Windows 10 / 11（均为 64 位）
权限 必须以管理员身份运行（安装、服务注册、目录写入均需要管理员权限）
端口 默认使用 80 / 443；如被占用需先释放或改用其它端口
离线安装包 官方 nginx 压缩包，文件名形如 nginx-1.24.0.zip，版本号需可从包名或目录结构识别
磁盘 每个实例需要独立目录，建议预留 200MB 以上
防火墙 如需对外提供访问，放行对应端口（默认 80 / 443）

三、安装前准备（离线环境）

  1. 在可联网的机器上下载官方 nginx Windows 版压缩包（.zip），拷贝到目标服务器。
  2. 确认目标服务器 80 / 443 未被其它程序占用（如 IIS、其它 nginx、Tomcat 等）。
  3. 确认将以管理员身份启动 nginxUI，否则安装阶段会因权限不足失败。
  4. 规划安装根目录。每个实例会在此目录下创建独立子目录，互不影响。

四、安装实例（离线安装）

进入左侧导航 安装实例，在页面顶部把安装方式切换为 离线安装，按三步向导完成。

第 1 步：选择版本

  • 点击 上传安装包…，选择准备好的 nginx 压缩包。
  • 工具会解压并校验包结构，成功后显示识别到的版本号；校验失败会提示具体原因。
  • 如上传错误，点击 清除 重新选择。

第 2 步：安装位置

  • 安装根目录 可手动输入，也可点击 选择目录… 选择。
  • 目录必须存在且当前账号（管理员）有写入权限。

第 3 步：实例名称

  • 名称格式固定为 nginx-win-ngui-N，前缀不可修改。
  • N 为 1～6 位整数且必须大于 0，不能有前导零。
  • 默认自动生成可用名称；如需修改，点击 自定义 N… 后输入。

安装结果

  • 安装完成后实例出现在「实例总览」，Windows 服务已注册但默认不启动。
  • 安装阶段只做 nginx -t 校验与服务注册，不会写入站点、代理或 HTTPS 配置，也不会预检端口占用。
  • 业务配置的常规做法：拿到后端应用服务器 IP 后，在外部改好 nginx.conf，再通过「配置文件编辑」统一替换。

五、实例总览与启停

左侧导航 实例总览 列出全部实例，并展示运行状态、版本、配置路径、端口等信息。

操作 说明
启动 启动对应 Windows 服务；启动前会先做配置校验
停止 停止服务，站点立即不可访问；会弹出确认框
重启 先停止再启动，用于让新配置生效
配置测试 执行 nginx -t，只校验不改动
更多 打开配置目录、日志目录、忽略/恢复实例、重命名等
监控开关 只控制本页是否采集与展示状态数据，不改写 nginx 配置

状态会定时自动刷新，界面与实际服务状态最长 10 秒内保持一致；如刚完成外部操作，可点击刷新立即同步。

六、配置文件编辑

选中实例后进入左侧导航 配置文件编辑。

  1. 读取文件：从磁盘加载当前 nginx.conf。
  2. 编辑：进入编辑态后可修改内容，此时「读取文件」等入口会置灰，避免覆盖未保存内容。
  3. 配置测试：执行 nginx -t，只校验语法与引用，不落地。
  4. 重新启动：应用当前内容并重启服务；执行前会备份原配置。
  5. 还原：放弃未保存修改，恢复为磁盘上的内容。

注意：nginx -t 不检查端口是否被占用，端口冲突只会在服务真正启动时暴露。

七、版本升级与回滚

左侧导航 版本升级，先确认页面顶部显示的是目标实例。

升级

  • 在线升级：选择版本列表中的稳定版后点击升级（需要外网可达）。
  • 离线升级：上传本地 nginx 安装包并校验，通过后执行升级。
  • 升级前旧版本二进制与配置会自动备份，升级过程中会提示阶段进度。
  • 升级期间会禁止重复触发，并锁定其它长操作入口。

回滚

  • 存在升级记录时 回滚 按钮可用，点击后恢复上一版本并重新启动服务。
  • 回滚同样会弹出确认框，说明对象、影响与可撤销性。

八、证书管理与 HTTPS

8.1 证书库

左侧导航 证书管理 用于集中管理证书文件：

  • 导入证书…：导入 PEM 证书与私钥，自动校验是否配对、是否过期。
  • 更换证书文件…：替换某条证书的证书/私钥内容。
  • 编辑信息…：修改名称、备注等描述信息，不改动密钥内容。
  • 删除证书：删除前会检查是否仍被站点引用。
  • 列表下方可查看该证书关联的实例与端口，并执行绑定/解绑。

8.2 替换站点证书

选中实例与证书后启动替换向导，向导会依次确认：目标实例、证书来源、写入方式（覆盖原文件 / 写入新路径并改写配置）、加密方式。

  1. 执行前自动备份原证书文件与配置。
  2. 写入后执行 nginx -t，失败自动回滚，不产生半配置。
  3. 校验通过后 reload 或重启，使新证书生效。
  4. 如需立即生效，可在向导中选择替换后立即重启。

8.3 恢复证书备份

替换向导中提供「恢复备份…」入口，选择历史备份记录后即可恢复证书与相关配置，恢复后同样会校验并重启。

8.4 为站点启用 HTTPS

左侧导航 站点管理，扫描出站点后选择目标站点，点击 启用 HTTPS 进入向导：

  • 选择站点与 HTTPS 监听端口（默认 443）。
  • 选择证书来源：证书库，或本地上传证书与私钥。
  • 可选启用「HTTP 跳转到 HTTPS」（301）。
  • 执行前会备份配置，写入 SSL 监听与证书指令后执行 nginx -t，失败自动回滚。
  • 完成后重启实例，用浏览器确认握手证书已更新。

九、Nginx 状态监控

左侧导航 Nginx 状态 展示连接数、请求数等指标。

  • 启用监控：向当前实例配置写入带标记的 stub_status 配置块，校验通过后应用；运行中的实例会自动重启。
  • 移除监控：只删除本工具写入的、带标记的配置块，手工编写的块不会被删除。
  • 实例总览中的监控开关只影响展示与采集，不改写配置；需要真正清理配置请使用本页的「移除监控」。

十、日志查看

左侧导航 日志查看 可按实例查看运行日志，便于定位启动失败、配置错误、证书错误等问题。nginx 自身的错误日志位于实例目录下的 logs/error.log。

十一、数据与备份

内容 位置说明
实例目录 安装时指定的「安装根目录」下的实例子目录，界面会显示完整路径
配置文件 实例目录下的 conf/nginx.conf，可在「配置文件编辑」中查看实际路径
运行日志 实例目录下的 logs/，含 error.log 与 access.log
升级备份 升级前自动生成，可在「版本升级」中用于回滚
证书备份 替换证书前自动生成，可在替换向导中恢复
Windows 服务 服务名 nginx-win-ngui-N，可在「服务」管理器中查看

十二、常见问题

现象 原因 处理方式
启动失败，日志出现 bind() ... failed (10048) 端口被其它进程占用；nginx -t 不检测端口 用 netstat -ano | findstr :80 找到占用进程并释放，或改用其它端口后重启
安装到一半失败 非管理员权限、目录无写权限、安装包结构不合法 以管理员身份运行；更换有写权限的目录；重新下载官方安装包
服务注册失败 缺少管理员权限或服务名已存在 以管理员身份运行；换一个未被占用的实例编号 N
升级失败提示文件被占用 nginx 进程仍在运行 先停止实例再升级；失败后使用「回滚」恢复
证书提示不匹配或格式不支持 私钥与证书不成对，或不是 PEM 格式 确认证书与私钥来自同一次签发，统一转换为 PEM 后重新导入
某按钮变灰无法点击 前置条件未满足，或另一个长操作正在执行 鼠标悬停查看原因与恢复条件，按提示处理后重试
界面状态与实际不一致 外部修改了服务状态 等待自动刷新（≤10 秒）或点击刷新

十三、操作红线

  • 不要在实例运行中直接替换 nginx.exe，请使用「版本升级」。
  • 不要在 nginxUI 执行长操作时，手工改写同一实例的配置文件。
  • 不要删除实例目录下的 logs/ 与备份目录，否则无法回滚与定位问题。
  • 不要在本工具写入的 stub_status 标记块内部手工修改，移除时应通过「移除监控」。

附录：三分钟快速上手

  1. 以管理员身份启动 nginxUI。
  2. 进入 安装实例 → 切换 离线安装 → 上传 nginx 压缩包。
  3. 填写安装根目录，确认实例名称，点击开始安装。
  4. 进入 实例总览，启动实例。
  5. 进入 配置文件编辑，替换为已准备好的业务 nginx.conf，先「配置测试」再「重新启动」。
  6. 进入 站点管理，为需要的站点启用 HTTPS。
  7. 进入 Nginx 状态，启用监控查看指标。
